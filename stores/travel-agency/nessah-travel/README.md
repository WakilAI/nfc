# Nessah Travel

Ouvrir `index.html`. Modifier les libellés, liens et leur ordre dans `links.js`.
Ordre : Avis Google, Instagram, Facebook, WhatsApp, Téléphone, Localisation. Avis Google est mis en avant en turquoise ; le footer indique le nom et l’activité.
Les six destinations fournies sont renseignées. Téléphone et WhatsApp : +213 556 70 49 60 ; existence du compte WhatsApp non vérifiée.
Le logo web est une copie optimisée avec les marges blanches réduites ; `assets/logo.jpg` et les plaques sources restent intacts. Les plaques sont dans `plates/` et sont publiées dans l’aperçu du commerce.
Style : blanc, bleu marine et turquoise des références, sans photo de plaque, QR ou symbole NFC dans la page.
Vérifier avec `node check.cjs` depuis ce dossier, ou `node check.cjs` à la racine pour l’annuaire complet.

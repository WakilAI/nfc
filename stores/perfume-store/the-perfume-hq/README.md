# The Perfume HQ

Page de liens statique en français, identité noire et champagne issue du logo fourni.
Ouvrir `index.html` directement ; modifier les boutons dans `links.js`.
Le logo original reste dans le dossier source fourni ; `assets/logo.webp` est la copie web optimisée, sans recadrage.
Les quatre références de plaques sont copiées dans `plates/` pour l’aperçu de l’annuaire.

Vérification depuis ce dossier : `node check.cjs`.
Le téléphone et WhatsApp utilisent le numéro algérien +213 770 07 67 06 fourni.
L’existence du compte WhatsApp et les destinations externes ne sont pas vérifiées.
